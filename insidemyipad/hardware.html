Hardware

← Hardware

Hardware is the physical iPad on which the software runs. It has 3 main categories:

  • Input/Output Devices
  • Processing Units
  • Storage

Input/Output Devices

Input/Output Devices are the components that allow the user to interact with the iPad. Some examples are:

  • Touchscreen: The screen that allows the user to interact with the iPad.
  • Home Button: The button that takes the user to the home screen and Touch ID.
  • Speakers: The components that produce sound.

Processing Units

Processing Units are the components that perform the actual computation on the iPad. Some examples are:

  • Central Processing Unit (CPU): The main processor of the iPad.
  • Graphics Processing Unit (GPU): The processor responsible for rendering graphics.
  • Digital to Analog Converter (DAC): The component that converts digital signals to analog signals usually for speakers.

Storage

Storage is the component that stores data on the iPad. Some examples are:

  • Main Memory (RAM): The storage for things running currently.
  • Hard Disk Drive (HDD): Storage that remains after the iPad is turned off.
  • Solid State Drive (SSD): Fast storage that is more expensive than HDDs.
