Inside My iPad: How Software Controls Hardware

Hardware →

Hardware is the physical iPad on which the software runs. It has 3 main categories:

  • Input/Output Devices
  • Processing Units
  • Storage

System Software →

System Software is the software that manages and operates the iPad's hardware. It has 2 main categories:

  • Operating Systems
  • Utility Applications

Application Software →

Application Software is the software that performs specific tasks for the user. Some examples are:

  • Notes
  • Web Browsers
