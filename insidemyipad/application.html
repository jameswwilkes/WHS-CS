Application Software

← Application Software

Application Software is the software that performs specific tasks for the user. Some examples are:

  • Notes
  • Web Browsers

Notes

Notes relies the OS to talk to the hardware in 3 ways:

  • Touchscreen: The screen that allows the user to interact with the iPad and type on the note.
  • Apple Pencil: The stylus that allows the user to draw and write on the iPad.
  • Bluetooth: The wireless technology that allows the iPad to connect to keyboards and other devices.

Web Browsers

Web Browsers rely the OS to talk to the hardware in 3 ways:

  • Touchscreen: The screen that allows the user to interact with the iPad and navigate the web.
  • Wi-Fi: The wireless network that allows the iPad to connect to the internet.
  • RAM: The memory that stores data and websites being visited for the iPad to use.
