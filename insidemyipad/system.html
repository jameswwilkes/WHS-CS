System Software is the software that manages and controls the hardware of the iPad. It has 2 main categories:

  • Operating Systems
  • Utility Applications

Operating Systems

Operating Systems handles 5 main functions:

  • Processor(s): scheduling tasks/multitasking
  • Memory :allocating RAM to open apps, frees up memory when software is closed
  • Input/Output (I/O) devices: touchscreen gestures, Apple Pencil, speakers
  • Applications: providing an interface and platform for apps to run
  • Security: manages user authentication FaceID/passcodes, user access rights, sandboxing apps

Utility Applications

Utility Applications are the software tools that help maintain and optimize the performance of the iPad. Some examples are:

  • Files: The application that allows the user to manage files on the iPad.
  • Settings: The application that allows the user to configure the settings of the iPad.
  • Diagnostic Tools: The tools that help diagnose and fix problems with the iPad.
